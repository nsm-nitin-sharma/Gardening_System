## Contribution Guidelines

1. Create a feature branch from `main` for new work.
2. Follow the existing code style and architectural patterns.
3. Write unit tests for all new service methods.
4. Submit a pull request with a clear description of changes.
5. Obtain at least one code review approval before merging.
